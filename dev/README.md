# Dev Jellyfin instance

Throwaway Jellyfin **12.2** for testing the plugin. Runtime state lives in `dev/jellyfin/`
(gitignored); delete that folder to start fresh.

```bash
docker compose -f dev/docker-compose.yml up -d     # start
docker compose -f dev/docker-compose.yml logs -f   # logs
docker compose -f dev/docker-compose.yml down      # stop
```

## First-run setup (once per fresh `dev/jellyfin/`)

1. Open http://localhost:8096 and complete the startup wizard (a local test admin account).
2. Dashboard → Plugins → Repositories → add
   `https://www.iamparadox.dev/jellyfin/plugins/manifest.json`
3. Catalog → install **File Transformation** (3.0.3.0 has a 12.2.0.0 build) → restart the server.
4. Dashboard → Playback → Resume → *Max resume percentage* = 100 (see PLAN.md, progress tracking).
5. Add a **Shows** library pointing at `/data/courses` (generated by `dev/make-fixtures.sh`, host: `dev/jellyfin/courses/`)
   and/or `/data/elearning` (real exports, mounted read-only; host path defaults to
   `/path/to/courses`, override with `ELEARNING_SOURCE=...` in `dev/.env`).
   Turn **off** every internet metadata and image fetcher (TheMovieDb, OMDb) and the NFO saver,
   otherwise courses get matched to random TV shows. Keep Embedded Image Extractor + Screen
   Grabber for episodes.
6. Dashboard → Plugins → E-Learning → tick the library under **Course libraries**, save.
7. Dashboard → API Keys → create one and save it as `JELLYFIN_API_KEY=...` in `dev/.env`
   (used by `dev/ui-view.py`).

## Version pin

The image is pinned to `version-12.2ubu2604` because `:latest` is already 12.4 and the plugin's
Jellyfin.Controller/Model package versions must match the server. Bump both together.
Don't downgrade an existing config folder; newer servers migrate the database irreversibly.

## Inspecting the library

- `set -a; . dev/.env; set +a; dev/ui-view.py [name]` — courses as the web client lists them.
- `dev/library-report.sh [path]` — raw Series/Season/Episode rows from the database.
- The "Courses" library on `/data/elearning` was created with all internet metadata/image
  fetchers off (only Embedded Image Extractor + Screen Grabber for episodes).
- Course index written by the plugin after each scan:
  `dev/jellyfin/config/data/data/elearning/course-index.json`.
